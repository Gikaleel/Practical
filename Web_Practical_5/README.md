# Практична робота №5 — Organic Breads

Це односторінковий сайт пекарні, створений за наданим референсом Nicepage.

# Структура

- `index.html` — розмітка усіх блоків сторінки.
- `style.css` — кольори, шрифти, сітки, розміри, оформлення карток.
- `script.js` — відкриття меню та вікна з інформацією про хліб.
- `images/` — фотографії, взяті з наданого скріншота завдання.

# Що зроблено

Зверстано головний банер, блок із шістьма перевагами, секцію з хлібом, каталог із 8 картками, блок про якість і Sweets Menu. Меню та кнопки `more` працюють. На малих екранах елементи перебудовуються, щоб не виходити за межі екрана.
