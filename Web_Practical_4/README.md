# Практична робота №4. Верстка трьох макетів

# Сторінки
- `index.html` — **A Trusted Reputation Built Over Time**, фотоколаж зі статистикою 
- `about.html` — **About Us / What We Do / Who We Are**, інформаційні блоки із круглими фото 
- `travel.html` — **Speak to our expert**, сітка з шести країн 
- `all.html` — всі три блоки на одній довгій сторінці, зі швидкою навігацією

# Структура
- `style.css` — усі стилі і сітки CSS Grid.
- `script.js` — робота кнопок `READ MORE` та демонстраційне повідомлення при виборі країни.
- `images/` — усі локальні фотографії, щоб сторінка працювала без завантаження зображень з інтернету
