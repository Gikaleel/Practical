# Практична робота №1 з вебтехнологій

# Що зроблено

За двома наданими зображеннями створено *дві вебсторінки*:

1. *`index.html`*— шість маркетингових карток, розташованих за допомогою CSS Grid. Використано всі шість готових SVG-ілюстрацій. Кнопка *Learn more* відкриває невелике вікно з поясненням послуги.
2. *`periodic-table.html`* — кольорова періодична таблиця зі 118 хімічними елементами. Для розташування елементів використано CSS Grid. Лантаноїди й актиноїди винесені в окремі ряди, як на зразку.
