# Практична робота №3 з WEB-програмування

Тема: верстка адаптивного сайту навчальних курсів за наданим макетом.

# Файли

- `index.html` — розмітка сторінки, усі розділи та форми.
- `style.css` — оформлення сторінки і адаптація під різні екрани.
- `script.js` — вибір навчального предмета та перевірка форми.
- `images/` — фотографії та іконки з матеріалів до практичної.

# Що є на сайті

- Перший екран з шістьма навчальними напрямками.
- Блок партнерів із фотографіями.
- Інформаційні картки програм і ресурсів.
- Статистика, місія, команда і відгук.
- Контактна форма з перевіркою полів.
