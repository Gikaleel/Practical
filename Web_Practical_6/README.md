# Практична робота №6. FOREFATHERS

Відтворення головного екрана вебсайту за наданими зображеннями (для ширини екрана понад 1200 px і менш як 1200 px).

# Файли

- `index.html` — структура сторінки: навігація, заголовок, текст, емблеми, діалогові вікна.
- `style.css` — оформлення, розташування елементів, медіазапити для різної ширини екрана.
- `script.js` — відкриття інформаційних вікон, мобільного меню та перевірка форми.
- `assets/hero-background.webp` — фонове зображення.
- `assets/hero-emblems.png` — білі емблеми внизу макета.
- `assets/logo.svg` — декоративний логотип у верхній частині.

# Основні особливості

- Весь текст, кнопки та емблеми створені як окремі HTML-елементи, а не вбудовані у фон.
- На широкому екрані великий заголовок і три нижні елементи розташовані як у зразку.
- На вузькому екрані структура змінюється за допомогою `@media (max-width: 1199px)`.
- Додатково передбачене меню для дуже вузьких екранів.
