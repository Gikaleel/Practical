# Практична робота з вебпрограмування

# Тема
Створення адаптивної вебсторінки для агентства нерухомості за наданим зразком.

# Файли
- `index.html` — структура сторінки, текст, картинки, меню, форми.
- `style.css` — оформлення, розміри, кольори та адаптація під телефон.
- `script.js` — відкривання меню, перемикання міст, перегляд фото та демонстраційні форми.
- `images/` — усі зображення з практичного завдання.

# Що реалізовано
- Верхнє меню з переходами до розділів.
- Банер із фоновим зображенням та формою.
- Шість карток міст, що перемикають головне фото міста.
- Галерея з шести фотографій, які можна збільшувати.
- Блок про агентів нерухомості та блок квартир.
- Контактна форма і футер.
- Адаптивна верстка для комп'ютера і смартфона.
